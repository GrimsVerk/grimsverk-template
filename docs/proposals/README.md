# Proposals

Ideas for new capability, written before there is any evidence for them.

This directory is deliberately **not** `docs/escapes.md` and **not** a project's
`docs/BACKLOG.md`. Those two are fed by runs: something went wrong, or something
was ruled on, and the entry records it. Everything here is the opposite — an idea
the owner had, with no run behind it. Keeping the two apart matters, because the
oracle resolves design decisions against logged evidence, and an idea that never
happened is not evidence.

**Nothing here is approved, and nothing here is built unprompted.** A proposal
leaves this directory in one of two ways: the owner moves it into a plan under
`docs/plans/`, or it is deleted. Until then it is text.
